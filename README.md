# 🚌 Naija Danfo Bus — Pure CSS Art

A Lagos "danfo" bus, sun, clouds, and road — all drawn from scratch using only **HTML and CSS**. No images, no icons, no JavaScript. Every part of the bus (roof, windows, stripes, door, headlights, wheels, number plate) is a plain `div` shaped and positioned with CSS.

🔗 Live Demo: https://peter-techie.github.io/css-danfo-bus/

## 💡 Why I Built This

I'm learning front-end web development through freeCodeCamp's Responsive Web Design Certification. After finishing the CSS Positioning section — relative, absolute, fixed/sticky positioning, and z-index — I wanted a project that would let me practice everything at once instead of just answering theory questions. A danfo bus felt like the perfect way to combine that with something proudly Nigerian.

## 🛠️ Skills Practiced

- `position: absolute` and `position: relative` to stack and place every part of the bus precisely inside one container
- The CSS box model (`width`, `height`, `border`, `padding` via `box-sizing: border-box`)
- `border-radius` to shape rounded corners (roof, windows, wheels, hubcaps)
- `linear-gradient()` for the sky background
- `box-shadow` to give the sun a soft glow
- Layering elements in the correct order so the bus parts don't hide behind each other
- Writing clean, organized CSS with clear class names for a multi-part illustration

## 🚀 How to Run It Yourself

1. Download or clone this repository
2. Open `index.html` in any web browser — that's it, no build tools needed
3. Want to edit it? Open the folder in VS Code, use the Live Server extension, and tweak the numbers in `styles.css` to change the bus's colors, size, or position
